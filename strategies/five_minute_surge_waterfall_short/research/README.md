# 研究说明

`src/backtest.py` 只使用标准库读取 `data/kline/okx/swap/5m/` 的确认 K 线，按单个合约顺序扫描，避免把研究结果或派生数组写入行情目录。它一次生成四类信号（20/30% × 突破/未突破前 4 小时高点），再分别模拟两种入场方式。

报告中的全历史比较是描述性证据。当前存续合约带来幸存者偏差，限价触价按 OHLC 理想成交，未计资金费率、队列、部分成交、强平和真实盘口冲击。

最新结果写入 `results/report.json`、`results/summary.csv` 和逐变体成交 CSV。覆盖 304 个合约和 35,697,069 根 5m K 线；突破/未突破为成对对照组。所有 8 个固定变体的组合净 R 均小于 0，30% 未突破 + 实体顶部限价虽然接近盈亏平衡，但只有 7 笔组合成交，不能作为上线依据。
