# 小网格敏感性研究

`grid_backtest.py` 是独立的价格条件研究入口，不改变 `src/backtest.py` 的策略基线，也不会把任何网格组合写回机器配置或运行时。

运行：

```bash
python3 strategies/extreme_negative_funding_110_short/research/grid_backtest.py --scan
```

固定资金费率门控为忽略，其他规则沿用基线；只遍历：

- 触发涨幅：`110% / 120% / 130%`；
- 触发后等待完整 5 分钟 K 线：`1 / 2 / 3` 根；
- 入场价上方初始止损：`10% / 15% / 20%`。

每个组合在 `results/grid/grid.csv` 有一行摘要，所有成交在 `results/grid/trades.csv`，完整定义和结果在 `results/grid/report.json`。基线的 `+80%` 日内资格门槛、`2.10 × 日开盘` 限价、半仓 `-20%`、剩余仓位保本和 `-40%` 目标、手续费与滑点保持固定。

报告把一个独立事件定义为每个 `(symbol, UTC day)` 的首次触发信号，并同时列出训练区与验证区事件数。这个计数只避免同一币种同一天重复计数，不代表统计学上的独立样本；只有验证区至少 30 个事件的组合才满足预先设定的筛选门槛。脚本不会自动选择或合并赢家，且本研究仍然是忽略资金费率的价格敏感性分析，不能替代资金费率门控回测。

当前行情结果（截至报告中的最新数据末端）共有 27 个组合，验证区事件数为 16、20 或 26，`0/27` 达到至少 30 个事件。因此本轮没有可晋级的最终参数。样本内外仅作方向提示：验证区排序第一的 `trigger_110_wait3_stop10` 为 26 个事件、21 笔成交，验证 PF `1.382`、复合收益 `+24.1%`；它仍然标记为样本不足，不能据此合并或上线。
