# 极限负资金费率 110% 逼空做空

版本 `0.1.0`，稳定标识 `extreme_negative_funding_110_short`。这是一个独立的研究候选策略，未接入 `Sources/`，也不修改或合并 `five_minute_surge_waterfall_short`。

## 数据与日界

- 输入是 OKX USDT 线性永续 **已确认的 5 分钟 K 线**。解析器丢弃未确认、未对齐、OHLC 不合法和重复时间戳的记录。
- UTC 日从 `00:00:00Z` 开始（北京时间 08:00）。只有包含日界第一根 5m K 线且从该日开盘到信号没有时间缺口的日才有效；不完整日不触发信号。
- 日内涨幅使用该 UTC 日第一根 K 线的开盘 `D` 为分母，运行高点 `H_t` 为截至已确认当前 K 线的最高价：`H_t / D - 1`。必须严格大于 80%，并且第一次达到 **+110% 涨幅**（`H_t >= 2.10D`）才产生一次候选触发。

## 资金费率门控

每个候选触发都必须匹配外部提供的资金费率快照。快照至少包含 `symbol`、`timestamp_ms`、`funding_rate`、`symbol_max_negative_rate`。使用不晚于触发 K 线收盘（`bar_open + 5m`）且在配置时效内的最新快照；当前验证默认时效为 480 分钟（8 小时），这是待用历史资金费数据复核的研究假设。`funding_rate <= symbol_max_negative_rate` 且上限必须明确为负数时才放行。缺快照、缺上限、上限不是负数、超时或比较不满足都会拒绝信号。绝不从价格、其他币种或缺失值推断资金费率。当前仓库行情没有该快照，因此默认扫描必须明确报告资金费率不可用并得到 0 笔交易。

## 入场

触发 K 线确认后，**下一根连续 5m K 线**才激活卖出限价单，价格固定为 `2.10D`（也就是日开盘上方 110%）。订单有效到该 UTC 日结束；跨日、时间缺口或日末未成交就撤单。若激活根开盘价大于等于限价，以开盘价成交；否则该根最高价触及限价，以限价成交；都未发生则继续等待。由最高价触发的盘中成交时间未知，该根不执行退出检查，从下一根 K 线开始检查，避免把同根低点当成先后顺序已知的利润。

## 仓位与退出

- 杠杆固定 1x；回测 `net_return` 按固定名义仓位计算为相对实际入场价的净收益率，手续费和滑点已计入，资金费率不计入收益。
- 设实际入场价为 `E`。初始止损 `S0 = 1.20E`（做空方向上涨 20%）。止损先于同一根 K 线的止盈检查；跳空越过止损按开盘价成交，否则按止损价成交。
- 第一个盈利位 `T1 = 0.80E`。价格向下触及后，按 `T1` 平掉 50%，并把剩余仓位止损改为 `E`；该修改从下一根 K 线开始生效。
- “再跌 20%”固定解释为**相对原始入场价再下跌 20 个百分点**，所以第二个盈利位 `T2 = 0.60E`（累计下跌 40%），触及后平掉剩余 50%。若同根同时触及两个盈利位，按已确认的低点依次完成 T1、T2；止损仍优先。
- 持仓遇到时间缺口，在缺口前最后一根收盘价退出；数据末尾按最后收盘价退出。退出价格和收益都记录部分平仓的加权结果。

## 研究边界

资金费率只作入场门控，当前版本不把快照费率推算为持仓资金费损益。报告不模拟盘口队列、部分成交、强平或跨日持仓。研究脚本、测试、配置和报告全部位于本目录；不会从运行时 Swift 源码读取 `data/` 或 `strategies/`。

```bash
python3 strategies/extreme_negative_funding_110_short/src/backtest.py --scan
python3 strategies/extreme_negative_funding_110_short/src/backtest.py --scan --funding path/to/funding_snapshots.json
python3 strategies/extreme_negative_funding_110_short/src/backtest.py --scan --ignore-funding
python3 -m unittest discover -s strategies/extreme_negative_funding_110_short/tests -p 'test_*.py'
```

`--ignore-funding` 是价格条件敏感性验证，不代表原策略的完整信号；它只跳过资金费率门控，其他入场、止损、分段止盈和数据质量规则不变。
