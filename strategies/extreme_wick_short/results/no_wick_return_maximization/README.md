# 取消上影线条件的直接做空实验

本轮将 `upper_wick_min` 固定为 `0.0`，也就是完全移除上影线过滤；仍保留严格滚动 24 小时涨幅 `>100%`、收阴、收盘位置、RSI 回落、成交量、ATR 风控、2 倍杠杆和原有成本模型。共扫描 432 组参数，行情一次加载到内存。

完整区间总净收益最高的网格项是 `grid_0028`：收盘位置 ≤40%、成交额 ≥20 根均值、RSI ≥50 且回落、取消前高突破门槛、止损 0.45 ATR、止盈 1R。它有 56 笔全局单仓成交，胜率 62.5%、PF 1.64、总净收益 13.49R，风险预算账户收益 6.91%。

但其回顾验证段只有 11 笔，胜率 45.5%、PF 0.81、净收益 -1.17R。按预设的训练段至少 50% 胜率/PF 1.3、验证段至少 50% 胜率/PF 1.5 门槛，没有任何无上影线组合通过；训练段单独最优项 `grid_0292` 虽有 74 笔完整成交，验证段胜率只有 25.0%、PF 0.32。

作为对照，保留上影线条件的 `grid_0580` 为 48 笔、68.8% 胜率、PF 2.12、17.17R。因此取消上影线后虽然增加了样本，但降低了验证稳定性和总净收益，当前不建议替换原候选。

完整证据见 [report.json](report.json)、[grid.csv](grid.csv)、[grid_0028_config.json](grid_0028_config.json) 和 [grid_0028_trades.csv](grid_0028_trades.csv)。配置见 [no_wick_return_maximization.json](../../research/no_wick_return_maximization.json)。
