# 研究记录

本目录保存规则解释和可复现研究的说明。`STRATEGY.md` 与 `config/strategy.json` 才是规则和参数真源；回测结果不能反向改写规则。

本版本来自一张 SAND/USDT 15m 截图。截图 K 线符合 setup 的大部分形态，但它的上影线约占振幅 27.4%，不符合 40% 上影线阈值；同时截图 24 小时高点相对低点涨幅约 69%，也不能证明满足“滚动 24 小时翻倍”。因此新规则采用“突破前高 + 大实体阴线 + 收盘位置 + EMA20 贴近 + 右侧确认”，没有复用翻倍条件的观察池。

当前仓库的 K 线导出早于截图所示的最新时刻，结果只能说明历史样本表现，不能验证截图后续是否真的下跌。运行回测后，`results/report.json` 和 `results/trades.csv` 记录生成时间、输入范围、交易样本和成本假设；至少积累 30 个独立事件并完成新时间段前推后，才有资格重新评估策略状态。

当前导出按最终规则扫描 288 个标的和 4,731,758 根 15m K 线，在全局单仓、24 小时成交额门槛和确认等待下只有 2 笔成交，合计 `+0.572R`。两个样本都在 24 根持有上限时退出；这个结果只证明回测管线可复现，不支持宣称胜率或收益稳定。
