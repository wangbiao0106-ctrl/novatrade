# 研究口径

本目录先做账单回放，再做价格层行为回放。账单可以确认成交、已实现收益、手续费、资金费、强平和保证金调拨，但不能可靠提供逐笔开仓/平仓标志、完整盘口、滑点或未实现盈亏。

研究分三层：

1. **账单事实**：按 `关联订单id + 交易品种` 聚合分笔成交，报告手续费、资金费、保证金和强平。
2. **风格标签**：用“零已实现收益的方向订单 + 相反方向的非零已实现收益订单”形成近似 episode，标明方向和不确定性。
3. **账单候选筛选**：只用 episode 入场前同品种的已实现结果做时间切分对照；全部 episode 只作描述基线。
4. **价格层行为回放**：以 episode 的时间和方向为标签，在下一根已确认 5 分钟 K 线开盘成交，按固定 ATR 止损、止盈、时间上限、手续费和滑点模拟；入场前 K 线特征只用于候选过滤。

不要把 `add_count`、持有时长、最终收益或事后表现作为入场条件。它们只用于判断分批建仓、救仓和尾部风险。

样本只有一个月左右，候选对照很容易被少数大单、单个品种或单一行情阶段主导。价格层结果以 R 为单位，不能直接换算到账户收益；K 线没有资金费、标记价格、盘口和合约乘数。下一阶段应补充更长账单时间窗，按交易日 walk-forward、按品种留一法验证，并加入资金费、盘口冲击、持仓规模和真实下单约束。

当前账单样本（2026-07-22 至 2026-08-22）有 64,000 条记录、1,523 个订单组和 443 个近似闭合 episode，其中空头 392 个、多头 51 个。永续账单口径的已实现净额为 `+4,558.38`，同期交易账户余额变动为 `+3,825.83`；episode 只归类出 `+82.29`，其余金额不能在缺少可靠开平仓标志的情况下强行归因。价格层成功模拟 432 个行为标签，训练段选出的 `short_after_24h_up_20pct` 在验证段为 `-1.04R`、测试段为 `-9.58R`，所以当前报告状态为 `not_promoted`，只能作为后续独立信号研究的假设。
