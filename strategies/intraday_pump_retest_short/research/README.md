# 研究记录

`src/backtest.py` 先从 `data/kline/okx/swap/5m/` 读取全部合规标的并聚合到内存，再以同一份 K 线运行默认规则和 72 组敏感性组合，避免参数验证重复读取硬盘。

结果：

- `results/report.json`：数据质量、阶段计数、账户资金曲线、样本量验收和限制。
- `results/samples.csv`：每个已缓存的突涨候选及其下跌段、缩量和收盘位置特征。
- `results/trades.csv`：通过全部条件且通过 ATR 距离风控的交易。
- `results/sensitivity.csv`：只用于敏感性观察，默认规则不从最高收益变体反向修改。
- `results/threshold_comparison.csv`：固定其他默认参数，分别比较 >20% 与 >30% 突涨阈值。

当前数据的模式非常稀疏，若没有交易或未达到 30 笔最低样本量，报告明确标记 `passed=false`，不能据此宣称策略有效。

## 最近一年半默认规则复核

`results/report.json` 已更新为 `2025-04-03T00:00:00Z` 至 `2026-10-03T08:00:00Z` 的完整行情结果：295 个合规合约、11,896,703 根完整 15m K 线、36 个候选突涨、1 个完整信号。该信号因 ATR 止损距离风控拒绝，最终没有成交，账户收益和回撤均为 0，`validation.passed=false`。

## 严格 >100% 观察锚点变体

`research/anchor_100.json` 将观察锚点从默认的严格 `>60%` 改为严格 `>100%`，其余 15m 形态、2 倍杠杆、成本和风控保持一致；结果写入 `results/anchor_100/`，不覆盖默认结果。

该段保留的是旧窗口的严格 `>100%` 观察锚点对照；本次默认规则重跑没有启动该变体的扫描。因此该锚点的旧结果不能当作最近一年半默认规则的结果，后续若需要比较应单独用 `research/anchor_100.json` 重跑。
