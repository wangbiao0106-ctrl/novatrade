# 策略交叉对比报告：我的「BTC门控·二次扫顶反转」 vs 「HLSR 高位流动性扫顶反转」

> 对比对象：`strategy_sweep_reversal/`（本会话定稿策略）与 `scripts/high_short_strategy.py`（HLSR）
> 对比原则：**同一份市场数据**（`data/market_export`，477 合约，2026-03-31 ~ 09-27）、同一时期、同口径指标（R 倍数、含手续费）。

---

## 一、设计对比

| 维度 | 我的策略（定稿） | HLSR（scripts/high_short_strategy.py） |
|---|---|---|
| 入场周期 | 1h | 15m（信号），1H/4H 定 regime |
| 标的池 | 177 个中低流动性山寨币（排除 BTC/稳定币/股票ETF商品） | 50 个"24h 涨幅>40% 且 24h 成交额>3000万U"的暴涨币 |
| 核心信号 | 288 根(12天)高位 → 首次扫顶+回落 → **二次扫顶**（高点更低、深度≥0.2ATR）| 摆动高点被扫+收盘回落（上影线/阴线/放量评分≥2）→ 破局部低点或回测失败的**右侧确认** |
| 附加过滤 | RSI≥62、量能≥1.5×均量、**BTC<SMA200 门控** | 4H regime（EMA20/50 空头或震荡）、zone 分类 |
| 止损 | 扫顶极端 + 0.5×ATR | 扫顶高点 + 0.25~0.5×ATR |
| 止盈 | **固定 2.2R + 96 根时间离场** | **三段结构目标**（支撑/中位/大低点）+ 分批 30/30/40 + 保本移动止损 |
| 风险约束 | R ∈ (0.2%, 15%) 之外放弃 | 同（代码一致） |
| 费用假设 | 0.05%/边 | 0.06%/边 + 0.02% 滑点 |
| 验证方法 | 单次训练/测试切分（120/60 天） | **3-fold 滚动前推**（60 训练/30 验证/30 测试，OOS=后 90 天） |
| 交易频率 | 0.33 笔/天（全市场） | OOS 合计仅 9 笔（后 90 天） |

## 二、同数据绩效对比（market_export，全期 + OOS 后 90 天）

| 组合（信号 × 标的池） | 笔数 | 胜率 | 盈亏比(R) | 期望 | 备注 |
|---|---|---|---|---|---|
| **我的信号 × 我的推荐池(177)** | 60 | **51.7%** | 1.69 | **+0.37R** | 后90天(OOS同窗): 31 笔 / 51.6% / +0.32R |
| 我的信号 × HLSR 暴涨池(50) | 30 | 30.0% | 1.68 | −0.19R | 后90天: 14 笔 / 28.6% / −0.28R |
| **HLSR × HLSR 暴涨池(50)，全期（fold1参数）** | 46 | 30.4% | **3.39** | +0.35R | fold2参数: 39笔/38.5%/+0.21R；fold3: 45笔/40.0%/+0.45R；最大回撤 5.1~9.2R |
| HLSR × HLSR 暴涨池(50)，其 walk-forward OOS | **9** | 55.6% | 3.04 | +1.28R | 样本严重不足（见 §三） |
| HLSR × 我的推荐池(177) | 3~4 | — | — | — | 其硬过滤"24h涨幅>40%且成交额>3000万U"在低流动池几乎不触发 → 两策略池子不兼容 |

**关键事实 1**：两个策略的 alpha 来自**不同的市场现象**——我的策略赚"平静小币的高位双扫顶反转"，在暴涨币上亏钱（−0.19R）；HLSR 赚"暴涨后的扫顶反转"，其硬过滤天然排斥低流动性池（只触发 3-4 笔）。两者 universe 几乎正交（50 池里只有 12 个落在我的推荐池）。

**关键事实 2**：HLSR 全期（其池，fold1 参数）46 笔、胜率 30.4%、但盈亏比 3.39、期望 +0.35R —— 与我的 60 笔/51.7%/1.69/+0.37R 在全期期望上**几乎相同**，但构成完全不同：它是"低胜率+大赢家"（结构止盈），我是"高胜率+中等赢家"（固定 2.2R）。其 OOS 9 笔 55.6% 明显是样本噪声（fold1 test 3 笔全胜 +4.49R/笔拉高均值）。

**关键事实 3**：HLSR 全期回撤 5.1~9.2R（我的推荐池最大回撤约 3.5R），其收益更集中、单笔更重。

## 三、统计可靠性对比

| 指标 | 我的策略（推荐池） | HLSR（OOS） |
|---|---|---|
| 样本 | 60 笔（OOS 后90天 31 笔） | 9 笔 |
| 胜率 95% 后验区间（Beta(胜+1,败+1)，2万次抽样） | 51.7% → **[39.3%, 63.8%]**；OOS31笔 → [34.9%, 68.3%] | 55.6% → **[26.6%, 81.6%]**（其报告自带） |
| 月度一致性 | 6/6 月正期望 | 仅 3 个 fold、互相矛盾（fold1 全胜/fold3 全败） |
| 结论 | 期望为正的可信度较高 | 单笔质量高但样本不足以定论 |

## 四、HLSR 参数在我的推荐池上的表现（交叉移植实验，已完成）

用其三个 fold 选出的参数直接跑全期（0.06%/边 + 0.02% 滑点）：

| 参数来源 | 我的推荐池(177) | HLSR 自身池(50) |
|---|---|---|
| fold1 参数 | 4 笔 / 0% / −1.03R | 46 笔 / 30.4% / +0.35R |
| fold2 参数 | 3 笔 / 33.3% / +0.70R | 39 笔 / 38.5% / +0.21R |
| fold3 参数 | 4 笔 / 25.0% / +0.03R | 45 笔 / 40.0% / +0.45R |

**结论**：HLSR 的"24h 涨幅>40% + 成交额>3000万U"硬过滤在低流动性池 180 天内只触发 3~4 次——两套策略的池子互不兼容，直接换池没有意义。真正的互补在**出场结构**（§五）。

## 五、互相可借鉴之处（融合实验已完成，见 §六）

**HLSR 值得我吸收的：**
1. **三段结构止盈 + 分批 30/30/40 + 保本移动止损**——它的实际盈亏比做到 3.04（我固定 2.2R 只有 1.69）。可以移植到我的 resweep 信号上回测（已做，见 §六）。
2. **右侧确认**（破局部低点/回测失败才入场）——比我的"二扫收盘直接入场"多一层过滤，可能提高质量（代价是样本减少）。
3. **3-fold 滚动前推**的验证纪律，比我单次切分更严格。
4. **24h 涨幅>40% 硬过滤**是一个清晰、可解释的动量前置条件——但注意它只适合暴涨币 universe，且把我策略的 alpha 直接过滤掉了（我的信号在其池上 −0.19R）。

**我值得 HLSR 吸收的：**
1. **BTC<SMA200 门控**（regime 层）——HLSR 用 4H 单币 regime，但没有大盘门控；牛市中段它的测试折全败可能与此有关。
2. **流动性分层认知**——HLSR 的选池只看涨幅和量，未意识到其 50 池的 alpha 也可能集中在其中低流动性部分（其池内 12 个推荐池成员 vs 38 个高流动成员可拆开验证）。
3. **样本量意识**——9 笔 OOS 不足以宣称达标；建议合并更长历史或放宽硬过滤。
4. 我的**逐笔可复现扫描器**（live_signal.py 与回测 60/60 一致）可作为其落地层参考。

## 六、融合实验结果（我的信号 × HLSR 出场结构，已完成）

在推荐池 177 个山寨币、同一 60 笔信号上，把 HLSR 的出场移植过来，与我的基线（固定 2.2R + 96 根时间离场）对比（成本统一 0.0016×价格/R，即 0.06%×2+0.04% 滑点）：

| 出场方案 | 胜率 | 盈亏比 | 期望 | 训练/测试 |
|---|---|---|---|---|
| **基线：固定 2.2R + 时间离场** | **51.7%** | **1.69** | **+0.37R** | +0.26R / +0.51R |
| 结构止盈 30/30/40 + 保本 + 移动 | 61.7% | 1.04 | +0.23R | +0.23R / +0.22R |
| 1/2/3R 分批 30/30/40 + 保本 | 63.3% | 1.07 | +0.31R | +0.20R / +0.45R |
| 1/3R 分批 15/85 + 保本 + 移动（最优融合） | 63.3% | 1.12 | +0.34R | +0.28R / +0.41R |
| 1/3R 分批 25/75 不保本 + 移动 | 46.7% | 1.87 | +0.29R | +0.10R / +0.53R |
| 2.2R + 1R 保本（不分批） | 38.3% | 2.73 | +0.24R | +0.19R / +0.31R |
| 2.2R + 1.2R 保本（不分批） | 43.3% | 2.31 | +0.30R | +0.26R / +0.35R |

**融合结论：HLSR 的分批/保本/移动止损移植到我的信号上无法超越基线。**
- 它能把盈亏比推到 2.2~2.7（保本后平均亏损变小），也能把胜率提到 63%（1R 部分止盈计入盈利），但**两者不可兼得，且所有变体期望（最高 +0.34R）都低于基线 +0.37R**。
- 原因：我的小币 resweep 反转腿偏浅（1R 命中 52%、2R 仅 29%），分批+保本会把大量"本可走完 2R+ 时间离场"的赢家提前在 1R 锁利或打成平局；而 HLSR 的暴涨币回撤深、结构目标远，分批结构才吃得开。
- **基线（固定 2.2R + 96 根时间离场）在我的信号上就是最优出场结构，维持定稿不变。** 融合代码与全部分析保留在 `fusion.py` 与 `out/fusion_grid*.csv` 供复查。
